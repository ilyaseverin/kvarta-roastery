# Кварта — обжарка кофе в Минске

[Сайт](https://kvarta-roastery-ilya.netlify.app) · [Репозиторий](https://github.com/ilyaseverin/kvarta-roastery)

Лендинг вымышленной минской обжарки: Next.js, TypeScript, shadcn/ui и Netlify. Цель — заявка на обратный звонок для подписки, заказа или вопроса.

**Что делал я, а что ИИ.** Я выбрал концепцию «Ритм недели», оценивал варианты и давал правки: вернуть календарную идею, усилить первый экран, перейти к тёплой тёмной теме и скруглениям. Код, тесты, подбор фотографий, публикацию и технические проверки выполнил Codex. [Фактический диалог](docs/ai-session.md) · [журнал этапов](docs/ai-worklog.md).

**Где ИИ ошибся и как это обнаружилось.** Первые варианты расходились с выбранной схемой и выглядели шаблонно — я указал на это при просмотре. Браузерная проверка ИИ обнаружила ошибку Origin за прокси: форма отклоняла заявки. Проверку исправили, добавили регрессионные тесты. Зависание сохранения после публикации устранили переносом обработчика в отдельную Netlify Function.

**Хранение и допущения.** На хостинге используется постоянный Netlify Blobs: атомарная запись предотвращает дубли одного номера за 10 минут, включая одновременные отправки. Он подходит существующему Legacy Free; встроенный Postgres потребовал бы смены тарифа. Локально — SQLite. Комментарий необязательный; рекламная атрибуция — первый переход вкладки. Телефон мастерской, стоимость доставки до 50 BYN и состав подписки в ТЗ не заданы: их не выдумывал. [Подробности](docs/operations.md).

**Что не сделано и что изменил бы.** Не подключён необязательный Telegram. Упростил бы декоративные заголовки и крупный логотип под тон мастерской. Для реального запуска добавил бы уведомления менеджеру и защиту от массового спама. Фото — иллюстрации процесса; [лицензии](docs/assets.md).

**Проверки.** 14 тестов, TypeScript, сборка и отправки на Netlify прошли. Мобильный Lighthouse: 99 / 100 / 100 / 100; [отчёт](reports/lighthouse-mobile.report.html), [результаты проверок](docs/verification.md).

Запуск: Node.js 22.17+, `npm ci`, `npm run dev`. Проверки: `npm test`, `npm run typecheck`, `npm run build`. Настройка хостинга — в [инструкции](docs/operations.md), секреты в Git не входят.
