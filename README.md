# Кварта — обжарка кофе в Минске

[Сайт](https://kvarta-roastery-ilya.netlify.app) · [Репозиторий](https://github.com/ilyaseverin/kvarta-roastery)

Учебный лендинг вымышленной мастерской: Next.js 16, React 19, TypeScript, Netlify. «Ритм недели» объединяет крупные «Чт / Пт», фотографию обжарки и авторские CSS-упаковки. Локальный шрифт, WebP, адаптивная вёрстка, лёгкий параллакс и reduced motion.

**Заявки.** Собственный `POST /api/lead` в Netlify Function: серверная проверка BY-номера, нормализация, рекламные метки, ошибки. Хранилище — постоянный Netlify Blobs: strong consistency и атомарные conditional writes сохраняют заявку и отметку времени вместе. Даже одновременные отправки одного номера дают одну заявку за 10 минут; дубли не продлевают окно. Выбор обусловлен существующим Legacy Free: встроенный Postgres потребовал бы смены тарифа. Локально — SQLite. Данные доступны владельцу в Netlify → Blobs → `kvarta-leads-v1`.

**Допущения.** Имя, телефон и интерес обязательны; комментарий — нет. Принимаются белорусские мобильные и стационарные номера. Атрибуция — первый переход в пределах вкладки, плюс адрес отправки. В ТЗ нет телефона мастерской, цены доставки до 50 BYN и состава подписки: неизвестное уточняет менеджер. Подписка строго 2 × 250 г за 54 BYN в месяц. Фото — иллюстрации процесса; [источники и лицензии](docs/assets.md).

**Человек и ИИ.** Пользователь выбрал направление, потребовал нешаблонный результат и поправил первую реализацию. ИИ разобрал ТЗ, предложил схемы, написал код и тесты, проверил сайт. Ошибки ИИ: слишком сильный акцент на фотографии вместо календаря; предложение Postgres до проверки Legacy-тарифа; неверная проверка Origin за прокси. Их выявили пользователь, проверка аккаунта и браузерные тесты; исправления отражены в коммитах. [Журнал работы](docs/ai-worklog.md).

**Проверки и ограничения.** 14 автоматических тестов, TypeScript, сборка, реальные отправки, проверка мобильной вёрстки и Lighthouse; [результаты](docs/verification.md). Telegram не подключён — пункт необязательный. При развитии добавил бы CRM, полноценный антиспам и реальные контакты. [Запуск и устройство хранения](docs/operations.md).

Запуск: Node.js 22.17+, `npm ci`, `npm run dev`. Проверки: `npm test`, `npm run typecheck`, `npm run build`. Netlify: `LEAD_STORAGE=netlify`, случайный `LEAD_HASH_SECRET`, затем `npx netlify-cli deploy --prod --context production`. Секреты в Git не входят.
