# Работа с ИИ

Лог ведётся по ходу выполнения, 16 октября 2026. Полный диалог остаётся в чате Codex; этот файл — журнал этапов, а не подмена экспорта сессии.

1. Пользователь передал ссылку на ТЗ. Сайт не открывался; ИИ сообщил ограничение и запросил сохранённую копию, не выдумывая требования.
2. Из MHTML извлечены требования. Подготовлены план и пять дизайн-схем. Пользователь потребовал нешаблонный дизайн и разрешил подобрать фотографии и эффекты.
3. Выбрано направление «Ритм недели» с фотографиями процесса. Первоначальные равные календарные карточки признаны слишком универсальными; композиция переработана.
4. Проверены официальные документы Netlify: Next.js, серверные обработчики, PostgreSQL и лимиты бесплатного тарифа. Пользователь поручил реализацию до завершения с самостоятельным тестированием.
5. Созданы конфигурация проекта, дизайн-решение и этот журнал. Дальнейшие результаты, найденные ошибки и проверки дополняются фактически.
6. Проверка Netlify выявила Legacy Free: встроенный Postgres недоступен без смены тарифа. Тариф сохранён; выбран Netlify Blobs с strong consistency и conditional writes. Одна запись содержит и заявку, и данные дедупликации, поэтому отказ записи не оставляет ложную блокировку.
7. Написаны 10 тестов. Все прошли; TypeScript нашёл необязательный ETag в SDK. Добавлена явная проверка. Оптимизация JPEG на Windows упёрлась в блокировку исходного файла; вывод перенесён в отдельные WebP-файлы.
8. Первая рабочая версия открыта в браузере. Пользователь сообщил об отклонении от дизайна и уточнил: первая схема + поздняя фотоконцепция, лендинг должен цеплять. Переработан первый экран: охристая поверхность, крупные «Чт / Пт», компактная мобильная последовательность. Проверено на 390 px.
9. Локальный API проверен реальными HTTP-запросами: параллельные отправки, форматирование номера, неверные данные, Origin, размер тела и отсутствие публичного чтения.
