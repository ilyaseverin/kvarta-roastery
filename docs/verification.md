# Проверки

16 октября 2026. Результаты дополняются после фактического выполнения.

* Unit/integration: 10 тестов пройдены. Включают 30 конкурентных запросов с одной созданной заявкой, границу 10 минут, повтор без продления окна, два соединения SQLite, валидацию BY и рекламные параметры.
* Локальный HTTP API: 8 одновременных отправок — один ответ 201, семь дублей; тот же номер в другом формате — дубль. Неверный номер — 422, повреждённый JSON — 400, неподдерживаемый Content-Type — 415, чужой Origin — 403, слишком большое тело — 413. GET — 405, заявки публично не читаются.
* TypeScript и production-сборка прошли до визуального уточнения. Повторная финальная проверка выполняется после изменений.
* Переработанный первый экран: проверена ширина 390 px, основная кнопка видна до нижнего края 844 px экрана, горизонтального переполнения нет. Финальная проверка остальных ширин и опубликованной версии — далее.
