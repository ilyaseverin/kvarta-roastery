# Проверки

16 октября 2026. Результаты дополняются после фактического выполнения.

* Unit/integration: 14 тестов пройдены. Включают 30 конкурентных запросов с одной созданной заявкой, границу 10 минут, повтор без продления окна, два соединения SQLite, валидацию BY и рекламные параметры, Origin за прокси и ответы при ошибках.
* Локальный HTTP API: 8 одновременных отправок — один ответ 201, семь дублей; тот же номер в другом формате — дубль. Неверный номер — 422, повреждённый JSON — 400, неподдерживаемый Content-Type — 415, чужой Origin — 403, слишком большое тело — 413. GET — 405, заявки публично не читаются.
* TypeScript и production-сборка после визуального уточнения и изменения обработчика прошли.
* Переработанный первый экран: проверена ширина 390 px, основная кнопка видна до нижнего края 844 px экрана. Проверено 320 px, горизонтального переполнения нет. Браузер: ошибка номера, выбор продукта, успешная отправка, сообщение о дубле; ошибка сети сохраняет заполненные поля.
* Netlify draft `6ad218b97d25ea5bad293154`: 8 конкурентных HTTP-запросов — один 201 и семь дублей; повтор в другом формате — дубль; иностранный номер — 422. Полный путь из браузера до Netlify Blobs пройден; приватное чтение подтвердило продукт и рекламную атрибуцию. Тесты используют только синтетические заявки QA.
* Lighthouse и последняя проверка постоянного production URL — выполняются на финальном этапе.
